# WebCraft — ويب كرافت

**We Design. We Build. We Launch. We Grow.**

Bilingual website for WebCraft, a software and digital solutions company. Arabic (RTL) is the default experience; English (LTR) lives under `/en`.

Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · Lenis

---

## Getting started

```bash
npm install
cp .env.example .env.local   # set NEXT_PUBLIC_SITE_URL, and Resend vars to deliver the contact form
npm run dev
```

| Command | |
|---|---|
| `npm run dev` | Dev server |
| `npm run build` / `npm start` | Production build / serve |
| `npm run typecheck` | TypeScript |
| `npm run lint` | ESLint |
| `node scripts/prep-media.mjs` | Re-encode screenshots in `design/captures/` → WebP + regenerate `src/content/media.generated.ts` |

## How languages work

- `src/app/[lang]/` is the root layout for both languages; it sets `<html lang dir>`.
- `src/proxy.ts` rewrites clean URLs (`/`, `/work/bay3`) to Arabic, serves `/en/...` as English, and 308-redirects `/ar/...` to the clean URL.
- `src/i18n/config.ts` — locales, direction, `localePath()` for building links.
- **UI copy:** `src/i18n/dictionaries/ar.ts` and `en.ts`. `en.ts` is typed against `ar.ts`, so a missing key fails the build.
- **Content with structure** (projects, services, FAQ): `src/content/*.ts`, each string written as `{ ar, en }`.
- Every page emits a canonical URL, `hreflang` alternates (Arabic = `x-default`), localized Open Graph, and JSON-LD. `sitemap.xml` lists both languages.

## Brand identity

**Mark — the folded W.** Four ribbon strips folded into a W (craft in the fold, digital layers in the planes) with a spark lifting off the final stroke (the launch).

| Asset | Where |
|---|---|
| Source mark (edit this) | `public/brand/webcraft-mark.svg` |
| React mark (inline SVG) | `src/components/ui/brand-mark.tsx` — keep paths in sync with the SVG |
| Lockup (mark + wordmark) | `src/components/ui/logo.tsx` |
| Favicon, apple icon, 512px logo | generated by `node scripts/prep-brand.mjs` |
| Facebook profile picture (1024×1024) | `public/brand/webcraft-facebook-profile.png` |
| Facebook cover (1640×924) | `public/brand/webcraft-facebook-cover.png` |

The social images are laid out in `design/social/*.html` (real brand fonts plus
the logo SVG) and exported by screenshotting those files at their exact pixel
size. Edit the HTML, re-export, replace the PNG. The cover keeps its content
inside the centre band Facebook shows on desktop, and clear of the bottom-left
area the profile picture overlaps.

**Palette** (all taken from the mark, defined in `src/styles/tokens.css`):

| Role | Token | Value |
|---|---|---|
| Primary — brand azure | `brand-500` / `brand-600` | `#4C7CFF` / `#3F57E6` |
| Accent — aqua spark | `aqua-400` / `aqua-700` | `#34D3C0` / `#0F766C` |
| Page ground (azure tint) | `canvas` | `#EAF0FF` |
| Alternate grounds | `mist`, `mist-2`, `tide` (aqua) | `#DFE8FF`, `#D2DDFF`, `#E2F7F3` |

Grounds are brand tints, not plain white; white is reserved for small elements (inputs, chips, tiles). Contrast ratios are documented at the top of `tokens.css`. `.on-brand` re-points text tokens for saturated blue panels.

## Contact

`src/config/site.ts` is the single source of truth for every public channel:
the official address `support.webcraft.eg@gmail.com` and the TikTok, Facebook
and Instagram accounts. It feeds the contact section, the footer and the
`sameAs` list in the organisation JSON-LD, so a channel changes in one place.
Brand glyphs live in `src/components/ui/social-icons.tsx` (lucide ships none).
No individual names, phone numbers or personal accounts are published, and no
phone or WhatsApp channel exists until an official company number does.

## Performance notes

Scroll reveals are CSS driven by one inline IntersectionObserver
(`src/components/motion/reveal-script.tsx` + `src/styles/motion.css`), not a
motion component per element — that is what lets above-the-fold text paint
before hydration. Worth preserving when adding sections:

- animate `transform` / `opacity` only — never `height`, `background-position`,
  `box-shadow` or `clip-path` on scroll or in a loop;
- decorative glows use the `glow` utility (a radial gradient), not
  `filter: blur()` on a large element; the only live `backdrop-filter` is the
  sticky header;
- wrap anything with an infinite animation in `data-loop` so it pauses
  off-screen;
- Lenis runs on fine-pointer devices only and its rAF loop sleeps when idle;
  parallax is desktop-only;
- keep `zod` (and other server-only libraries) out of client components — import
  form constants from `src/lib/validations/contact-fields.ts`.

## Content rules

Everything on the site is verifiable: every project links to a live URL, screenshots are captures of the live products, and technology tags were detected in the deployed builds. There are no invented statistics, clients or testimonials — add real ones only when they exist.

Social links in `src/config/site.ts` are the official WebCraft accounts only — add a platform there, and it appears in both the contact section and the footer.

## Folders outside the app

- `design/captures/` — raw headless-Chrome captures of the live projects (source for `prep-media.mjs`).
- `design/raw-screenshots/` — the earlier manual captures. **Not public**: two contain real end-user personal data and must never go back into `public/`.
- `legacy/` — the previous Arabic-only presentation layer, the old lime/violet logo files and old docs, kept for reference. Excluded from TypeScript, lint and the build; safe to delete once no longer needed.
